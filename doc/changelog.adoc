[#pratt-changelog]
== Changelog

What changed in pratt in each version of webcpp, newest first, one line
per change. "Unreleased" is what the next version brings. The release notes
of every version are on webcpp's index page.

[#pratt-changelog-unreleased]
=== Unreleased

// tag::unreleased[]
* Added emscripten as a target: the tests and examples run under Node.
* Fixed `calc::environment` failing to compile with a stateful allocator
that has no default constructor.
* Added the `WEBCPP_PRATT_NO_EXCEPTIONS` configuration macro, defined
automatically or by the developer.
* Added a changelog, the page's last appendix, with each version's changes.
* Changed `config.hpp` to include `<webcpp/config.hpp>`, webcpp's
configuration, which the build adds.
* Added `WEBCPP_NO_EXCEPTIONS`, which disables pratt's exceptions with every
webcpp library's.
// end::unreleased[]
