= pratt: Pratt parsing for {cpp}
:toc: left
:toclevels: 1
:idprefix:
:sectanchors:
:example-caption!:
:attribute-missing: warn

pratt is a header-only engine for Pratt parsing, top-down operator
precedence, in {cpp}20, one of the libraries of
https://github.com/webcpporg/webcpp[webcpp]. It knows no token, no operator
and no tree: a program gives it a stream of tokens and a grammar that says
what each token means, and gets back the grammar's node or an error, as a
value. A calculator built on the engine comes with it, exact in decimal by
default.

This page teaches pratt concept by concept: why each exists, its smallest
example, its variations and its rules. Every program it shows was compiled
and run, natively and for wasm32-wasip2 and wasm32-wasip3, and printed the
output shown under it. The <<reference,reference>> that closes it lists
every name the headers declare.
